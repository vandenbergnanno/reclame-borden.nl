# Veld-mockupfoto's

Per veldtype komen hier straks eigen foto's te staan van de plek waar het reclamebord daadwerkelijk hangt, gefotografeerd vanuit meerdere hoeken. Deze worden later gebruikt om een gegenereerd ontwerp te tonen zoals het er in het echt bij zou hangen (de "meerdere-hoeken-weergave").

- `voetbal-zijlijn/` — reclameborden langs de zijlijn van een voetbalveld
- `hockeyveld/` — reclameborden rondom een hockeyveld
- `scorebord/` — scoreborden
- `plattegrond/` — plattegronden/informatieborden

Elke map is nu leeg (op een `.gitkeep` na) en wordt later gevuld met eigen, door De Mediagraaf aangeleverde foto's.
