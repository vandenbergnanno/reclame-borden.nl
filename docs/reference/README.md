# Referentiemateriaal

Deze map is bedoeld voor achtergronddocumenten die de context van het project vastleggen, maar die geen onderdeel zijn van de applicatiecode. Ze worden in een latere fase aangevuld, onder andere met:

- De organisatieanalyse van De Mediagraaf
- Het stagewerkplan
- Overige Word-documenten met onderzoek, afspraken of procesbeschrijvingen die relevant zijn voor deze tool

Deze bestanden zijn nu nog niet aanwezig. Zet ze hier neer zodra ze beschikbaar zijn, bij voorkeur met een korte, beschrijvende bestandsnaam (bijv. `organisatieanalyse-mediagraaf.docx`, `stagewerkplan.docx`).
